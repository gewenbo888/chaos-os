# Chaos OS · 混沌操作系统

A system to understand complexity, emergence, and nonlinear dynamics.

**Live:** [chaos-os.psyverse.fun](https://chaos-os.psyverse.fun)

## Modules

- **Butterfly Effect** — Lorenz system with two diverging trajectories, ε slider, divergence time
- **Attractor Basins** — Double-well potential, particle animation, basin switching, metastability
- **Emergence Engine** — Conway's Game of Life 20×20, play/pause/step, entropy & emergence score
- **Feedback Mapper** — 5 feedback systems with loop diagrams + time series charts
- **Phase Transition** — 1D Ising model, Metropolis algorithm, M vs T order parameter curve
- **Chaos Analyst** — Synthesis of 6 findings with recommended actions

## Stack

Next.js 16 · TypeScript · Tailwind CSS v4 · App Router · `src/app/` · No chart libraries — hand-coded SVG
